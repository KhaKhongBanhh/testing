## 6. Kết luận (Conclusion)

Kết quả thực thi **54 kịch bản System Test** (31 test case theo kế hoạch gốc và 23 test case mở rộng) cho thấy:
1. Các luồng nghiệp vụ chính (Happy Paths) và các kiểm tra biên cơ bản trên giao diện & API của 4 phân hệ **Movie, Room, Seat, Showtime** (tạo mới hợp lệ, kiểm tra rỗng/âm/bằng 0, chặn trùng số phòng, chặn trùng vị trí ghế, chặn lịch chiếu quá khứ, chặn trùng giờ chiếu cùng phòng, làm tròn 30 phút, tính giá ghế theo hệ số `1.0x / 1.5x / 2.5x`) hoạt động đúng, đạt **28/31 Pass (90,32%)** trên bộ test case gốc.
2. Tuy nhiên, quá trình kiểm thử thực tế đã phát hiện **7 lỗi phần mềm (`BUG-01` → `BUG-07`)** mà báo cáo cũ chưa phát hiện ra, nổi bật là: lỗ hổng thiếu kiểm tra xác thực/phân quyền trên các API thêm/sửa/xóa (`BUG-07`), lỗi cập nhật phim không gửi kèm `status` (`BUG-03`), thiếu kiểm tra tập giá trị enum (`BUG-05`), và ánh xạ sai các lỗi nghiệp vụ về mã HTTP `500` (`BUG-01`, `BUG-02`, `BUG-06`). Cần khắc phục các lỗi này trước khi nghiệm thu triển khai (UAT/Production).
